# Ludo Ludo - Survival Game Project
Demo Video: https://youtu.be/i0pAA2p0xgc

## Controls
Arrow keys to move

Mouse to look around

K to open the skill tree

E to interact with the NPC

I to open the inventory
## Build Instructions
Clone the repository into an existing Unity project and build!
